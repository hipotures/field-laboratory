## Opis

Projekt calendar-mcp to serwer protokołu MCP (Model Context Protocol) napisany w Pythonie. Działa jako interfejs między dużymi modelami językowymi (LLM) a API Google Calendar. Umożliwia modelom LLM wykonywanie operacji na kalendarzu za pomocą naturalnych zapytań językowych. Projekt integruje możliwości AI z zarządzaniem harmonogramem. Nie zawiera dodatkowych funkcji poza tym interfejsem.
