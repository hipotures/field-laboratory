## Opis

**TODOIT** to zaawansowany system zarządzania zadaniami z integracją MCP i interfejsem CLI. Obsługuje hierarchiczne zadania, zależności między listami oraz inteligentne priorytetyzowanie. System zapobiega pętlom zależności i automatycznie oznacza rodziców jako ukończone po zakończeniu podzadań. Oferuje dynamiczny system tagów z kolorami oraz szczegółowe statystyki postępu. Baza danych SQLite zapewnia trwałość, a interfejs MCP umożliwia integrację z Claude Code. Aplikacja wspiera import/eksport w formacie Markdown oraz śledzenie historii operacji. Zbudowana w Pythonie z użyciem SQLAlchemy i Pydantic. Dedykowana do zarządzania projektami wielozespołowymi oraz osobistą produktywnością. Zapewnia niskie czasy odpowiedzi i wysoką wydajność.
